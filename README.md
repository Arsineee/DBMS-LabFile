# DBMS Lab File

Hey! Welcome to my DBMS Lab Repository.

This repository contains the SQL programs and practical work I completed as part of my Database Management Systems (DBMS) lab. The experiments helped me understand how databases work in real-world applications, from creating tables and managing records to using advanced SQL features for automation and data handling.

## About This Repository

The main purpose of this repository is to practise SQL queries and understand the concepts of relational databases through hands-on experiments using MySQL.

Instead of just learning the theory, I have tried to understand how each concept works by implementing it through practical SQL programs.

## Experiments Included

- **Experiment 2 – ER Diagram to Relational Schema:** Creating tables for an e-commerce database and implementing primary keys, foreign keys, constraints, and relationships.
- **Experiment 3 – SQL Queries and Operations:** Working with selection, projection, aggregate functions, `GROUP BY`, `HAVING`, `CASE`, `ORDER BY`, and joins.
- **Experiment 4 – Joins, Subqueries and Query Analysis:** Practising different types of joins, nested queries, and query execution plans using `EXPLAIN`.
- **Experiment 5 – Views and Recursive CTEs:** Creating views, checking view updatability, and exploring employee reporting hierarchies using recursive queries.
- **Experiment 6 – Stored Procedures and Triggers:** Implementing stored procedures, salary validation, error handling, transactions, and salary audit logs.

*Note: The list above covers the experiments included in this repository. Other experiments can be added as the lab work progresses.*

## Technologies Used

- **MySQL** – To create databases, tables, and execute SQL queries.
- **SQL** – To manage data and implement database operations.
- **Relational Database Concepts** – Primary keys, foreign keys, constraints, and table relationships.
- **Advanced SQL Features** – Views, joins, subqueries, triggers, stored procedures, and recursive CTEs.

## How to Run the SQL Files

1. Install MySQL and open MySQL Workbench or another compatible SQL editor.
2. Download or clone this repository.
3. Open the SQL file for the experiment you want to run.
4. Execute the script in the correct order.
5. Check the output of the queries and verify the results.

**Important:** Some experiments depend on databases and tables created in earlier experiments, so make sure to run the required setup scripts first. Queries designed to generate errors should be tested separately.
